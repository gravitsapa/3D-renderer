# 3D-renderer by gravitsapa

## Зависимости
В проекте используются библиотеки Eigen и SFML, подключенные с помощью git submodule

Используется библиотека OpenCV, которая должна быть установлена

## Сборка
Для сборки используется CMake. Собрать на Linux можно с помощью команд

```console
mkdir release
cd release
cmake -DCMAKE_BUILD_TYPE=Release ..
make
```

## Запуск
Запускать нужно исполняемый файл `3D-renderer`.
Он принимает следующие параметры: `Width` `Height` `Object`.
`Width` и `Height` - разрешение окна приложения. 
`Object` - объект для демонстрации. Может быть одним из слов coffee, house, chess

Пример запуска:
```console
cd release
./3D-renderer 600 600 coffee
```

В открывшемся окне будет визуализирован выбранный 3D-объект. 
Объект можно вращать с помощью мыши, нажав на него и удерживая ЛКМ.
